Basemap sessions

Start one ArcGIS basemap session on demand.

What you see

A normal topographic map appears above. The session result displays its style family and expiration time; it does not replace the map automatically.

How it works

The sessions/start REST endpoint creates a temporary session token. Applications using the session billing model must use this token when requesting basemap styles or tiles. The map above uses its ordinary default tile-based model, not the session token.
