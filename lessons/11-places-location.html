Locate a place by ID

What you see

The API result contains longitude and latitude. After the request, the map pans to the returned location and adds an orange marker.

How it works

Place Details can return a location field in the Location price group. This lesson requests only location instead of all attributes, avoiding unnecessary attribute groups.

Try it

Copy a Place ID from the Nearby Places lesson and locate it. Change the initial map center or marker style in the HTML.

What's next?

Use the same point as a stop for a routing request.

API key / access

The API key must allow Places. The location field belongs to a separate metered price group.
