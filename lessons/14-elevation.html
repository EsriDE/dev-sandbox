Elevation at a point

What you see

Clicking the map selects coordinates and moves the orange marker. The elevation result is displayed both above that marker and in the information bar.

How it works

The Elevation REST API returns a point with a z value in metres. This example reads result.point.z (not raw JSON) and labels that point using a text graphic.

Try it

Click a hill and then a nearby valley, requesting a height for each. Change the initial point coordinates in the HTML to compare another location.

What's next?

Compare multiple points or display elevation in a 3D scene.

API key / access

The API key needs Elevation access. Each Get elevation click sends a request; values cannot be permanently stored under the Places/Elevation service terms.
