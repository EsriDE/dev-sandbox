Calculate a route

What you see

Two colored map markers show the start and destination. The resulting route is a blue line following streets, and the result bar reports distance and time when available.

How it works

The service solves a real street-network route and returns a polyline. One ArcGIS Graphic renders the line; other Graphics mark the stops. The map zooms to the returned route.

Try it

Click two different positions on the map, then Calculate route. In the HTML, change the default stops in the stops array and run again.

What's next?

Add intermediate stops, directions or a travel mode selector.

API key / access

The API key must allow Routing. Each Calculate click issues a routing request.
