    Find places near a point

    What you see

    An orange marker identifies the center. A Places near-point search adds blue markers for actual matching locations, along with a clickable result list.

    How it works

    The Places REST endpoint returns each place with its name, place ID, and x/y location. Map Graphics draw those coordinates. Clicking a result pans to it.

    Try it

    Click another part of Marburg and search again, or replace cafe with restaurant. Use a returned Place ID in the attribute lessons.

    What's next?

    Request extra attributes only for the place you select to avoid unnecessary billed groups.

    API key / access

    The API key requires Places access. Each search issues one Places request; additional attribute groups are metered separately.
