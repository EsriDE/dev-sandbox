Drive-time service area

What you see

An orange point identifies the origin. After calculation, the shaded blue polygon shows roads reachable within the selected time.

How it works

The ArcGIS Service Area REST API uses a road network, not a radius around the point. It returns polygon rings that are drawn using an ArcGIS Graphic.

Try it

Click another location and calculate again; compare 5 and 15 minutes. In the HTML change the initial origin coordinates.
