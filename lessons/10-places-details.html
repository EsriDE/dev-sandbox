Place contact details

Request the details attributes field group of a place using its ID.

What you see

The map starts near the documented Esri sample place in Redlands. This lesson requests non-spatial attributes only, so no result point is plotted. Use the Place Locations lesson to request and map coordinates. A small JSON result shows website or telephone when the provider has that information. Some fields may be null if unavailable.

How it works

The Places /places/{placeId} endpoint supports requestedFields. This example uses one published example Place ID; if it is no longer available, replace the ID. Do not use requestedFields=all: each extra attribute group may be billed separately.

Try it

Edit requestedFields (contactInfo:website,contactInfo:telephone) and inspect the response. Search for another Place ID in the Nearby Places lesson.

What’s next?

Combine this with nearby search and build a small place details panel.
