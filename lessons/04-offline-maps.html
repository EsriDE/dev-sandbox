Prepare maps for offline use

Offline mapping has two distinct steps: prepare a Web Map and offline map areas in the portal, then download them in a supported native application. A normal browser map cannot itself use those downloaded offline map areas.

1. Which map content can go offline?

  • Esri basemaps: Esri vector and raster basemaps generally support offline packaging. Other tile services need appropriate tile export capabilities.
  • Feature layers: a feature service generally needs the Sync capability enabled for offline workflows.
  • Web Maps: the Web Map and all required layers must support offline use. Configure offline mode and map areas in the portal.
  • Other services: dynamic map services, WMS, or unsupported reference layers require additional review and may block an offline map.

2. Inspect a public portal Web Map

Paste a Web Map item ID from your ArcGIS portal. This tool reads public Web Map JSON and checks the Sync capability of accessible feature services. It is a preliminary check, not a guarantee that a map can be packaged.

The example ID is a public Web Map; it is not necessarily offline-enabled.

    Open ArcGIS portal · Open Map Viewer

    This example uses the public ArcGIS Online portal endpoint. Private or organization-only Web Maps require user authentication; the sandbox API key does not sign you into the portal. For ArcGIS Enterprise, adapt the portal REST URL and authentication.

    3. Prepare an offline area in the portal

    1. Open Map Viewer, sign in, and create or open a Web Map with compatible basemap and feature layers.
    2. Save the map. Open its item details, then Settings → Offline and enable offline mode. If unavailable, check each layer's capabilities.
    3. Select Manage Offline Areas → Create offline area. Draw a rectangle or polygon, set the level of detail, name the area, and save.
    4. Wait for the portal to package the area. A mobile/native app built with an ArcGIS Maps SDK for Native Apps can subsequently download and display it offline.

    The live map at the top is an online preview; the dropdown switches styles and shows the geographic content a basemap provides. The inspector reports the layers referenced by a public portal Web Map, and, when possible, whether feature services advertise Sync.

    1. Switch between vector topographic and raster imagery. Note that offline packages use different tile formats.
    2. Inspect the example Web Map, then paste the ID of one of your own public Web Maps.
    3. Open its portal item page and compare the inspector's observations with Settings → Offline.
    4. Open the code panel, change the map's center, and run the lesson again.

    Limitations

    This lesson does not download tiles, create packages, switch the web application offline, or change portal settings. Portal configuration needs a signed-in account with sufficient privileges. Offline map preparation with an ArcGIS Location Platform account has partial product support; see the account requirements below before planning a production workflow.
